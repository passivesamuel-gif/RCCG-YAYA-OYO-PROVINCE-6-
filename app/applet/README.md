# RCCG YAYA Oyo Province 6 E-Library

A Christian digital library published by RCCG YAYA Oyo Province 6, open to everyone.

## Developer Guidelines
> **IMPORTANT**: Do not show infrastructure or technical terms in the UI (no Firebase, Firestore, Storage, backend, database, collection, document, repository, bucket, token, UID, API, server, endpoint, JSON, SDK, rules, index, quota, localhost, stack traces, or raw error codes like auth/... or storage/...). Always use plain, warm, professional, church-appropriate language.
